# Карта навыков — витрина на GitHub + Cloudflare R2

Как это устроено:

- **GitHub Pages** отдаёт саму страницу (`index.html`) и список работ (`works.json`). Бесплатно, сервер не нужен.
- **Cloudflare R2** хранит тяжёлые файлы: картинки, видео, музыку. Бесплатно до 10 ГБ, скачивание не тарифицируется.
- **`add_work.py`** запускается только у тебя на Mac: загружает файл в R2 и дописывает запись в `works.json`.
- Посетитель только смотрит. Сам он ничего загрузить не может, а у тебя на странице нет ничего, что можно взломать.

Условия бесплатных тарифов могут меняться — перед регистрацией загляни на сайты сервисов.

---

## Шаг 1. GitHub (один раз)

1. Зарегистрируйся на github.com и создай **публичный** репозиторий, например `skill-map`.
   Бесплатный GitHub Pages работает только с публичными репозиториями: всё, что в нём лежит, видно всем.
2. Распакуй этот архив и открой папку в терминале. Затем:
   ```
   git init
   git add .
   git commit -m "Первая версия"
   git branch -M main
   git remote add origin https://github.com/ТВОЁ_ИМЯ/skill-map.git
   git push -u origin main
   ```
   При `push` GitHub попросит войти. Пароль от аккаунта не подойдёт — нужен Personal Access Token
   (Settings → Developer settings → Personal access tokens) или проще: приложение **GitHub Desktop**.
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch →
   Branch: `main`, папка `/ (root)` → Save.** Через минуту-две страница откроется по адресу
   `https://ТВОЁ_ИМЯ.github.io/skill-map/` — именно эту ссылку вставляешь в LinkedIn.

## Шаг 2. Cloudflare R2 (один раз)

1. Зарегистрируйся на cloudflare.com, в меню выбери **R2 Object Storage**. Cloudflare может попросить привязать
   банковскую карту — прочитай условия до того, как вводить её.
2. **Create bucket** — придумай имя, например `skillmap-media`.
3. Открой созданный bucket → **Settings → Public Development URL → Enable**. Cloudflare покажет адрес вида
   `https://pub-xxxxxxxx.r2.dev` — скопируй его. Это публичный адрес, по нему посетители будут видеть файлы.
   > Адрес `r2.dev` Cloudflare считает «для разработки»: у него есть ограничение на число запросов,
   > при большом наплыве посетителей он может отвечать ошибкой 429. Для скромного портфолио этого хватает.
   > Если страницу начнут смотреть массово, подключи к bucket свой домен (**Settings → Custom Domains**),
   > затем впиши новый адрес в `r2_config.json` и выполни `python3 add_work.py sync`.
4. На главной странице R2 найди **Account ID** — скопируй. Там же **Manage API tokens → Create API token**:
   права **Object Read & Write**, доступ только к своему bucket. Сохрани **Access Key ID** и **Secret Access Key**
   (секрет показывается один раз).

Названия кнопок в панели Cloudflare иногда немного меняются, но смысл шагов тот же.

## Шаг 3. Скрипт на твоём Mac (один раз)

```
pip3 install boto3
python3 add_work.py init
python3 add_work.py check
```

`init` спросит Account ID, ключи, имя bucket и публичный адрес и сохранит их в `r2_config.json`.
**Этот файл нельзя выкладывать на GitHub** — он уже указан в `.gitignore`. Если ключи всё же утекли,
удали токен в Cloudflare и создай новый.

## Как добавлять работы

```
# картинка или видео в навык Blender
python3 add_work.py add render.png --branch blender --sub lowpoly --note "Таверна"
python3 add_work.py add walk.mov   --branch blender --sub anim    --note "Цикл ходьбы"

# навыки Blender: lowpoly, midpoly, highpoly, anim, sculpt, anatomy
# уровень английского: --branch english --sub B1 (подтверждение — скриншот теста)
# писательство: просто запись о главе, без файла
python3 add_work.py add --branch writing --note "Глава 12 опубликована"

# музыка для плейлиста (играет после нажатия «Войти»)
python3 add_work.py music theme.mp3 --title "Название трека"

# посмотреть всё, убрать лишнее
python3 add_work.py list
python3 add_work.py remove 7 --delete-file
```

Без параметров скрипт сам спросит ветку и навык цифрами. Флаг `--dry-run` показывает, что будет сделано,
ничего не загружая. Флаг `--push` сразу выкладывает обновлённый `works.json` на GitHub; без него выложи
вручную: `git add works.json && git commit -m "Новая работа" && git push`. Страница обновится через минуту.

Текстовые файлы до 200 КБ записываются прямо в `works.json`, остальные файлы уходят в R2.

## Видео из Blender

Браузер проигрывает не всё. Надёжно играет **MP4 или MOV с кодеком H.264**. В Blender:
*Output Properties → Output → File Format: FFmpeg Video → Encoding → Container: MPEG-4 (или QuickTime),
Video Codec: H.264, Audio Codec: AAC.* Кодеки ProRes, PNG, DNxHD и контейнеры AVI/MKV браузеры обычно не играют.
Если у тебя уже есть такое видео, добавь флаг `--convert`, и скрипт перекодирует его через `ffmpeg`
(на Mac: `brew install ffmpeg`). Скрипт предупредит сам, если заметит неподходящий кодек (для этого тоже нужен ffmpeg).

Совет: для сайта хватит 720p или 1080p при 6–8 Мбит/с — ролик минут на десять уместится в пару сотен мегабайт.

## Музыка и авторское право

Браузеры запрещают запускать звук, пока посетитель не нажмёт на страницу, поэтому на входе показывается экран
**«Войти»**: нажатие запускает музыку. Есть и кнопка «Войти без музыки», а выключить звук можно в плеере.

Загружай только свою музыку или треки с разрешающей лицензией (CC0, CC-BY — с указанием автора).
Чужие записи, например саундтрек из игры, в публичном хранилище могут привести к жалобам и блокировке.

## Проверить у себя

```
python3 -m http.server 8000
```

и открой `http://localhost:8000` — это вид посетителя. Адрес `http://localhost:8000/?edit=1` открывает
режим редактора: там работы хранятся только в твоём браузере и на публичный сайт не попадают.

## Превью для LinkedIn

В `index.html` в начале есть теги `og:title` и `og:description` — поправь текст под себя. Чтобы в ленте была
картинка, положи изображение 1200×630 рядом со страницей, раскомментируй строку `og:image` и впиши полный адрес
картинки. Если LinkedIn показывает старое превью, обнови его в инструменте LinkedIn Post Inspector.

## Что где лежит

| Файл | Зачем |
|---|---|
| `index.html` | сама страница (режим посетителя и режим редактора) |
| `works.json` | список работ и плейлист — его видят все |
| `add_work.py` | скрипт загрузки (только у тебя) |
| `r2_config.json` | твои ключи R2 — **секрет, не публиковать** |
| `r2_config.example.json` | пример настроек |
